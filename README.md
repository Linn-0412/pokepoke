# ポケポケおすすめパック計算ツール

Pokemon TCG Pocket のデッキに足りないカードを集計し、どのパックを引くと効率がよいかを期待値で並べるWebアプリです。データはブラウザの `localStorage` に保存します。

## 起動

```bash
npm install
npm run dev
```

本番ビルド確認:

```bash
npm run build
```

テスト:

```bash
npm test
```

## 使い方

1. `パック` タブでパックを選び、カード画像をタップして「ほしいものリスト」に追加します。
   - ◇〜◇◇◇◇ の絵柄をタップすると「どの絵柄でもOK」、☆以上をタップすると「その絵柄が欲しい」として登録します。
2. `デッキ` タブで QR 取り込み、またはカード名・ワザ名検索からデッキを作り、所持枚数を入れます。
3. `おすすめ` タブで「今引くならこのパック」、ランキング、不足カードごとの一番出やすいパック、警告を確認します。

## カードDB

`public/card-db.json` に全カード(日本語名・ワザ・収録パック・レアリティ・絵柄違い)と、パックごとのレアリティ別カード枚数・排出率を同梱しています。生成元:

- [GameWith カード一覧](https://gamewith.jp/pokemon-tcg-pocket/462535): 日本語名、ワザ、収録パック、画像
- [flibustier/pokemon-tcg-pocket-database](https://github.com/flibustier/pokemon-tcg-pocket-database): QRのカードID、弾ごとの排出率(レアパック・+1パック込み)
- [PokeAPI](https://github.com/PokeAPI/pokeapi): ポケモン名の日英対応(照合用)

新弾が出たら更新します:

```bash
npm run build:cards            # 照合結果のサマリを表示
npm run build:cards -- --verbose  # 名前の一致度が低い対応も一覧表示
```

GameWith に新しいパックが追加された場合は `scripts/build-card-db.mjs` の `GW_PACK_SET` にパックキーと弾コードを追記してください(未登録だと警告が出ます)。

カード画像は GameWith の画像を直接参照しています(リポジトリには含めていません)。

DB未収録の新弾などは、`パック` タブ下部の「手動パック」で従来どおりプール枚数を手入力できます。手動パックの排出率の初期値は GameWith の「通常封入(99.950%)」表を1パックあたり期待枚数に換算したものです(出典: https://gamewith.jp/pokemon-tcg-pocket/466420)。

## QR / コード取り込み

`デッキ` タブの `QR / コードから追加` から、ゲーム内の共有QR画像、QRのBase64文字列、JSON、簡単なテキストデッキリストを取り込めます。

ゲーム内QRは非公式に解析された形式を利用しています。アプリ更新で形式が変わった場合や、画像が荒い場合は読み取れないことがあります。QRのカードIDは同梱のカードDBで日本語名に変換し、「どの絵柄でもOK」として登録します。同名でもワザが違うカードは別カードとして扱います。

## データ移行

ヘッダーの `書き出し` でJSONを保存し、別端末では `読み込み` から復元できます。壊れたJSONや古い形式でもアプリが落ちないよう、読み込み時に正規化しています。

## 計算ロジック

計算は `src/domain/calculator.ts` に純粋関数として分離しています。

- 全デッキのカードを集約 (DBのカードはカードID+欲しい絵柄、手入力カードはカード名)
- 必要枚数と所持枚数はデッキ間の最大値
- 収録パックは和集合
- 足りないカードだけを対象化
- `p(c,P) = 排出率[レアリティ(c)] / P.プール枚数[レアリティ(c)]`
- DBのカードは、そのパックに入っている欲しい絵柄すべての `p` の合計 (排出率はパックの弾ごとの値)
- パック得点は対象カードの `p(c,P)` の合計
- `約何パックに1枚か` は `1 / 得点`

ユニットテストは `src/domain/calculator.test.ts` にあります。
