# ポケポケおすすめパック計算ツール

Pokemon TCG Pocket のデッキに足りないカードを集計し、どのパックを引くと効率がよいかを期待値で並べるWebアプリです。データはブラウザの `localStorage` に保存します。

## 起動

```bash
npm install
npm run dev
```

本番ビルド確認:

```bash
npm run build
```

テスト:

```bash
npm test
```

## 使い方

1. `パック` タブでパックを追加し、レアリティごとの排出カードプール枚数を入力します。
2. `デッキ` タブでデッキとカードを追加します。カード名、レアリティ、所持枚数、必要枚数、収録パックを入れます。
3. `おすすめ` タブで「今引くならこのパック」、ランキング、不足カード、警告を確認します。

排出率の初期値は GameWith の「通常封入(99.950%)」表を、1パックあたり期待枚数に換算したものです。

出典: https://gamewith.jp/pokemon-tcg-pocket/466420

通常パック向けの初期値なので、ハイクラスパック、レア封入、色違いカードが絡むパックでは、アプリ内の `排出率を調整` から必要に応じて変更してください。公式の提供割合を確認できる場合は、そちらを優先してください。

## QR / コード取り込み

`デッキ` タブの `QR / コードから追加` から、ゲーム内の共有QR画像、QRのBase64文字列、JSON、簡単なテキストデッキリストを取り込めます。

ゲーム内QRは非公式に解析された形式を利用しています。アプリ更新で形式が変わった場合や、画像が荒い場合は読み取れないことがあります。読み取ったQRはカードの「プレイ上の同一カード」を表すため、レアリティや収録パックは手入力データを優先し、未設定なら後から確認してください。

## データ移行

ヘッダーの `書き出し` でJSONを保存し、別端末では `読み込み` から復元できます。壊れたJSONや古い形式でもアプリが落ちないよう、読み込み時に正規化しています。

## 計算ロジック

計算は `src/domain/calculator.ts` に純粋関数として分離しています。

- 全デッキのカードをカード名で集約
- 必要枚数と所持枚数はデッキ間の最大値
- 収録パックは和集合
- 足りないカードだけを対象化
- `p(c,P) = 排出率[レアリティ(c)] / P.プール枚数[レアリティ(c)]`
- パック得点は対象カードの `p(c,P)` の合計
- `約何パックに1枚か` は `1 / 得点`

ユニットテストは `src/domain/calculator.test.ts` にあります。
